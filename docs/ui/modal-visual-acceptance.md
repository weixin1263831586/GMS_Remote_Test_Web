# 弹框逐项验收：深紫色工程控制台（2026-11-16）

本文件是 **PR #18 的未完成验收清单**，不是功能/视觉已达标声明。设计基准是用户在会话中提供的十张参考效果图：SSH 用户名检测、测试报告导入、设备租约确认、路由连通性、报告分析、固件烧写、报告诊断和 Tailscale 等。

## 设计与业务双重要求

- 原项目 ModalManager / EmbeddedModalController / ClusterModalController 的打开、关闭、ESC、焦点恢复、Tab、堆叠、用户权限、设备租约与操作事务必须保持不变。
- 共用色彩、字体、边框 token；**独立业务 DOM** 必须按操作目的拆分（来源/目标、设备/镜像、条件/动作、摘要/详情等），不可只在旧表单外多套一层卡片。
- 参考图中的非真实功能不得造假：例如设备租约时长/申请流、固件烧写多模式/伪进度、导入报告后的统计预览，如果后台现有流程没有真实数据与操作接口，不得生成虚假字段或按钮。保持当前产品能力与清晰反馈优先。
- 保留连续紫灰外框、斜切角装饰、标题分段线、精简底栏、实心紫色操作按钮，不用渐变色。不得通过根级 clip-path 裁切真实边框、输入框或滚动内容。
- 打开弹框后仍能辨认背后的业务界面；遮罩 40% 紫黑、blur(3px)，避免恢复此前 72% + blur(14px) 的全黑背景。
- 统一基础字号：标题 16px、表单与按钮 13px、说明 12px；复杂工作区保留自身宽度与内部滚动，普通表单自然定高。参考图是视觉语言，不是强制全屏等比例放大。
