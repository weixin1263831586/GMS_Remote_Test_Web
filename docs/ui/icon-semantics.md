# 全局图标、颜色与操作文案规范

## 设计原则

- **语义优先**：图标表达真实动作，不因为某个图标更醒目就取代其含义。按钮的可访问名称依赖清楚的文字，不得只靠颜色或图形表达。
- **按场景选择形态**：公共功能区优先使用 `/static/icons/ui.svg` 线性 SVG；测试界面的设备/烧写/VNC/网络操作保留旧版彩色 Emoji（装饰性、`aria-hidden`），其中 Remount 按钮使用彩色 `⚡` 图标，设备重启保留原始 `⏻` 字符（仅图标使用 `--danger-color` 显示红色，文字不变），不混用“刷新”符号。独立品牌与站点 favicon 保留真实来源。
- **彩色但克制**：对于线性 SVG，统一在 `web/static/css/ui-foundations.css` 用操作语义着色：蓝（连接/状态/刷新）、青（复制/文件传输）、紫（配置/分析/流程）、绿（成功/启动）、琥珀（注意/电源/重新挂载）、红（破坏性动作/停止/锁定）。测试界面保留彩色 Emoji 的高辨识度，并保持一致尺寸与间距。
- **可读性**：主色实心按钮及危险按钮内的图标优先保持与白色文字一致；禁用按钮图标置灰。颜色不能代替“刷新”“删除”“断开”等文字或 `aria-label`。
- **动态状态**：使用 `GmsUi.icon(symbol)` 或 `GmsUi.testEmoji(glyph)` 与静态模板一致地渲染状态按钮；刷新中、断开中、重连中与 VPN 状态不能把彩色图标退化为黑白线条、纯文本或不同语义图标。
- **测试页工具栏几何**：设备区的 10 个 ADB 操作按钮保持在同一水平行，1792px 桌面参考视口不能出现第二行或水平溢出；窄视口可横向滚动，不允许截断文字或通过挤出第二行隐藏操作。VNC 和操作控制区继续使用现有布局。「刷新套件」静态及刷新中状态均用彩色 🔄；「开始测试 / 停止测试 / 启动中 / 停止中」不显示图标，按钮按文字宽度收窄。
- **文件浏览入口**：测试页「选择报告」、报告分析页「上传报告文件夹」、GSI 烧写弹框的脚本及 System 镜像文件浏览按钮均使用彩色 `📁`。仅用于分类、目录字段说明的图标维持各自设计，文件上传仍使用上传图标。
- **接入弹框与日志空间**：ADB 设备接入 / USB/IP 设备接入弹框的标题统一使用 `🔌`，正文保持原有接入流程。测试页设备/操作/日志标题栏按实际内容压缩，但设备列表可视高度为 100px：前三行常规卡片（每行 28px、行距 4px）完整显示，第四行顶部位于 102px、不应在未滚动时露出；列表上下内边距及边框通过裁切余量处理，第 4 行及以后在设备列表内部纵向滚动。闲置上传进度条不占位，有进度信息时自动展开；不以压扁设备列表换取日志空间。

## 典型操作语义

| 动作/内容 | 图标 symbol | 说明 |
| --- | --- | --- |
| 刷新列表、重新请求最新状态 | `refresh` | 仅用于真实刷新/同步，不用作通用标题装饰 |
| 测试开始、停止、过渡状态 | 无图标，仅「开始测试 / 停止测试 / 启动中 / 停止中」文本 | 按钮根据文案自动收窄，保留原状态颜色和禁用行为 |
| 设备重启、VNC 重启 | 设备重启红色 `⏻`；VNC 重启 `🔄` | 电源符号保留原字形，仅设为主题红色；按钮文字与操作功能不变 |
| ADB Root / Remount | 测试页 `⚡` | 表示设备高级系统操作，文字保留 `Remount`，不更改命令执行逻辑 |
| 恢复出厂并擦除数据 | `eraser` | 与日常清理日志区分 |
| 锁定、解锁、锁定状态 | `lock` / `unlock` / `shield` | 与权限操作一致 |
| Wi-Fi、ADB、USB/IP | 测试页 `🛜` / `🔌` / `📱` + 明确文字 | 彩色 Emoji 搭配“连接 Wi-Fi”“ADB 接入”“USB/IP 接入”，不以图形单独解释通道 |
| 烧写固件、烧写 GSI | 测试页 `🔥` / `🔥` | 保留旧版高辨识度图标，文字明确区分固件与 GSI，不以火焰代表真实设备状态 |
| 复制命令/报告 | 测试页 `📋`，其他页面可用 `copy` | **复制**不表示已经部署或执行 |
| 文件下载/上传 | `download` / `upload` | 和保存到浏览器、服务端接收的动作保持一致 |
| 执行计划的修改与扫描范围选择 | `settings` / `search` | 不误用 `refresh` |

## 源码与验证

- SVG 定义在 `web/static/icons/ui.svg`，公共颜色及测试页 Emoji 尺寸由 `ui-foundations.css` 管理。Shell 引用带缓存版本的 CSS 和 JS。
- 修改图标时同步检查对应 `data-click`、`data-tools-action` 的实现，尤其注意显示文案与实际操作是否一致。
- 运行 `tests/architecture/test_ui_icon_semantics.py` 与 `tests/runtime_ui/test_ui_foundations.py`，并核对 Actions 的截屏；静态一致不代替业务状态和设备真机验证。
- 外部系统 favicon、公司品牌图标、设备来源自带图标保持真实来源，不统一替换为拟制品牌 SVG。
