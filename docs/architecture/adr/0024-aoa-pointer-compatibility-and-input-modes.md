# ADR 0024：AOA 指针兼容与显式输入模式

- Status: Accepted
- Date: 2026-11-04
- Related: [ADR 0023](0023-aoa-direct-touchscreen-and-stable-hid-set.md)

## Context

此前为避免 Settings/System 的 Mouse 条目，统一改成直接触摸屏。但旧模板按指针
模式实测的映射不一定是按轴缩放：同一个 `click 180 525` 会出现落点变化，设备端的
可视指针也消失。报文长度、逻辑坐标范围不变不能保证 Android 最终坐标兼容。

## Decision

1. 未声明输入模式的旧模板使用 `pointer`，注册与原实现完全相同的指针描述符，
   不自动重写模板坐标。直接触摸 `direct` 作为显式选项保留。
2. 输入模式和注册后的稳定等待时间保存到 Profile metadata 的 `hid_touch_mode`
   与 `hid_settle_seconds`；等待默认 2 秒，允许 0..10 秒。单条调试、整段回放、
   导入导出、手动烧写接续和自动化恢复使用相同选项。
3. 已有 version 2 标定来自直接触摸；缺少模式字段时按 direct 识别。新标定上下文
   记录模式。切换模式使当前标定失效，不能复用另一种模式的实测比例。
4. 按整段脚本需要的 HID 通道一次性注册，再等待稳定；重连重建相同模式和通道。
   不在执行到某条命令时才添加鼠标/键盘，也不按 Settings 页面动态切换描述符。
5. 远端 Worker 必须声明 `aoa_hid_modes_v1`，否则拒绝回放或带 AOA 的烧写，避免旧
   执行器忽略模式参数而再次产生坐标变化。

## Consequences

兼容鼠标模式可保留旧的坐标映射及指针行为，仍可能使系统显示 Mouse 条目。
AOA 主机无法在保留鼠标的同时只对特定 Settings 页面隐藏其条目；该行为由 ROM 决定。
提前注册与等待可以缓解动态加载，不能保证不同布局下的菜单坐标不变。模板需要在
选定输入模式下验证；可以在进入 System 后插入 sleep 等待布局稳定。

直接触摸模式仍可用于避免指针分类造成的界面变化，但必须使用该模式下验证的坐标。
两种模式都保持设备租约、物理端口绑定与 fencing 校验，不自动重放结果不明的输入。
软件测试确认描述符选择、旧坐标报文不变、等待先于输入及配置传递；不替代真机验证。
