# ADR-0035: 对话工单分析直接展示 kkagent 最终总结

- 状态：已采纳（Accepted）
- 关联：ADR 0013、0031、0034

## 背景

对话 Agent 复用单工单分析队列，但固定的诊断章节、关键结论引用格式和
格式修复轮会把 kkagent 的总结转换成报告。对话需要直接展示最终总结，
同时保留身份边界、可恢复队列和只读取证检查。

## 决策

- 对话适配器在内部提交 `output_style=summary`；页面和晨报继续使用
  `diagnostic`。HTTP 请求契约不新增可切换输出策略的参数。
- 使用现有持久字段 `mode=issue:<id>:summary[:full|incremental:<version>]`
  保存总结模式，不新增 SQLite 列。重试只复用相同输出模式的任务，执行
  账本也区分输出模式，避免与旧诊断报告或请求混用。
- 总结提示词复用诊断的实质取证和安全规则，允许 kkagent 自行组织答案。
  结果读取成功终态的最终文本，接受普通文本和自选 Markdown；不强制
  章节、JSON schema 或固定格式的结论条目。证据不足仍执行同会话补证据，
  修复提示词保持总结模式。
- 对话直接展示最终总结，不添加报告状态前缀、不按报告长度限制截断，
  不进行第二次模型改写。任务进度和失败仍由原有步骤与消息展示；会话的
  凭据脱敏、owner 校验及失败时排除历史结果的规则继续生效。
