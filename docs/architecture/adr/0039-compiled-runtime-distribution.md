# ADR-0039：编译发行版的 Agent 分发与持久化备份

- 状态：已采纳（Accepted）
- 关联：ADR 0003

## 背景

独立发行版使用 native 程序和单独的持久化配置、数据目录。直接复制开发
目录会泄露 Controller 源码；仅保留 Web 资源则会丢失 Agent 分发能力。
版本目录的 data/configs 软链接也不符合原有备份工具的默认目录契约。

## 决策

1. 使用现有规范 Agent 打包器，从生成的插件载荷构造 universal 包。将
   归档字节、版本和公共 bootstrap 写入临时构建模块，再由 Nuitka 编入
   程序。临时模块不进入发行目录，源码泄漏检查不增加例外名单。
2. Registry 复用现有 manifest 签名、摘要、下载和 bootstrap 公钥绑定。
   编译版读取内嵌载荷；源码版继续使用既有目录和同版本不可变校验。
3. 编译版备份和恢复显式指定持久化 data/configs 根目录。仅解析这些
   运维选择的根，目录内部仍拒绝软链接，归档格式与源码版保持兼容。
4. 定时备份复用 root 停服编排：先停 Worker，再停 Controller，备份后
   恢复原先运行的服务；失败同样恢复。备份进程对源目录只读，输出目录
   独立于 data/configs，禁止将输出嵌套在源内。
5. 初始化保存 CA 文件路径和稳定密钥路径，重装同步本地 Worker 的
   Controller 地址，保留套件目录、并发设置和密钥材料。

## 验证

回归覆盖无源码目录的 Agent manifest/下载/bootstrap、签名输入和摘要、
初始化与重装、加密备份/恢复、软链接边界、输出目录校验，以及成功和
失败备份的服务恢复。native 生产 Smoke 校验实际 Worker 配置、备份密钥
和 Agent 分发接口；真实设备与系统级部署仍由发行验收执行。
