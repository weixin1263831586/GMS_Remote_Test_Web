# 本机配置目录

配置布局、加载顺序、密钥迁移及备份以[配置体系](../docs/deployment/configuration.md)为准。

- `examples/`：Git 跟踪的脱敏配置模板；AOA 命令的共享要求见[用户指南](../docs/aoa/user-guide.md#命令配置与共享约定)。
- `local/`：本机部署配置和非敏感环境变量，不入库。
- `secrets/`：凭据、证书及按用户隔离的集成配置，不入库；目录 0700，私密文件 0600。

复制代码不会恢复本机配置。`data/` 也包含账号库、账号 AOA 配置及部分安装密钥，
清理或仅迁移配置前应按配置主文确认保留范围。当前布局不需要兼容软链接。
