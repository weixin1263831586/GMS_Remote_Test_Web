加载 USBIP 架构视图…

01接入链路

物理 Android 设备 → Windows/Linux USB Source → Worker 虚拟总线

02职责与边界

Source 负责导出，Worker attach 与测试，Controller 处理权限、租约和指令

03故障与恢复

USB 重枚举可能断开映射；完整烧写须依来源能力交还 Source 执行

加载 AOA 架构视图…

01Profile / 回放

工作台录制与标定；Profile 按 owner 隔离，回放支持暂停、恢复与终止

02执行链路

Worker 绑定物理 USB 端口，以 AOAv2 注入 HID 触点与按键

03ADB 就绪判定

回放完成不等于 USB 调试就绪；必须执行 ADB 往返检查

加载 FIRMWARE 架构视图…

01烧写阶段

固件校验 → 设备识别 → 进入支持的模式 → 烧写 → 结果校验

02执行与所有权

本地 Worker 可执行 upgrade_tool / fastboot；来源设备先交还 Source

03失败保护

Loader / MaskROM 重枚举不可假设持续在线；Linux Source 不支持的整包烧写拒绝执行

加载 TEST / FLOW 架构视图…

01执行阶段

权限预检 → 资源租约 → Worker Poll → Tradefed 运行 → 结果回报

02职责边界

Controller 分配任务；Worker 维护原生日志与结果，平台索引已登记报告

03闭环与产物

按证据分析问题，可关联 Redmine 与 Gerrit；失联不等于跨主机续跑

加载 AGENT / ANALYSIS 架构视图…

01诊断路径

上下文与工单 → 预采集日志、APK、SDK / 代码证据 → 分析复核

02执行与追踪

Controller 返回 run_id，后台分析状态独立跟踪并回送当前运行结果

03安全与沉淀

按工单属主隔离，引用可追溯；取消 Agent 跟踪不等于取消后台任务
