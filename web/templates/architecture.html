GMS Remote Test 系统架构

Controller 统一认证和调度；Worker 主动轮询命令并回报状态；Agent Runtime 通过独立 Service Token 使用受控能力。

部署角色

Web Browser

通过 HTTPS、Session Cookie 和 WebSocket 访问 Controller。

Agent Runtime

Codex / Kimi / kkagent 使用 gms-rt CLI 与 MCP；Service Token、scope、ACL 和 Approval Token 均由 Controller 校验。

FastAPI Controller

Web UI、认证、任务调度、SQLite 状态、报告、审计与外部系统集成。生产入口为 HTTPS。

Build / External Services

受审计 SSH 连接 {{BUILD_SERVER_LABEL}}；集成 Redmine、Gerrit、AI 与 OpenGrok。

控制平面

Linux Worker A / BWorker Token
→Heartbeat / Poll / ACK / Artifacts
FastAPI Controller命令队列 · Lease · Job 状态
⇢命令随 Poll 响应返回
Worker 执行面Tradefed · ADB · Fastboot

逻辑命令由 Controller 发往 Worker，但网络连接由 Worker 主动发起。Controller 不建立额外的反向 Shell 通道。

Worker 与测试执行

Linux Worker A

  • CTS / GTS / VTS / STS 套件
  • 本地 USB 或 USB/IP 导入设备
  • Job 日志、结果和 Artifact 回传

Linux Worker B

  • 独立能力与设备清单
  • Device Claim / Lease 所有权
  • 断线后按 generation 重新注册

设备数据平面与 USB/IP 接入示例

Local USB

Android 设备直接连接 Worker，由本机 ADB / Fastboot / upgrade_tool 使用。

Windows USB Source

usbipd-win 提供 USB/IP；完整固件烧写可交还 Source Agent 执行。

Linux USB Source

支持 USB/IP 共享、分配和重连；完整固件烧写能力按支持矩阵 fail closed。

USB/IP 是设备接入示例，不代表平台整体拓扑。不同来源的固件烧写能力并不相同。
