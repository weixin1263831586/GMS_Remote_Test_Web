📖 GMS测试流程指南

🚀 完整测试流程指南

📦 步骤1: 一键安装Skill和CLI（可在任意Linux主机执行）
curl -k -fsSL "{{ request.url.scheme }}://{{ request.url.netloc }}/api/agent/install.sh" | bash -s -- --paircode <配对码> 📋 复制
gms-rt-system-selfcheck && gms-rt-devices-list 📋 复制
💡 -k 仅用于自签名 Controller 的首次取脚本；安装器随后固定 CA 并严格校验下载。管理员在 Web 生成配对码完成安装；selfcheck 通过即可使用，升级用 gms-agent update。
🏥 步骤2: 测试主机网络连通性检查
gms-rt-ssh-ping 📋 复制
gms-rt-vpn-status 📋 复制
💡 检查VPN连接状态（如果需要VPN访问设备）
📱 步骤3: 设备检查
gms-rt-devices-list 📋 复制
💡 列出所有可用的测试设备，确认目标设备在列表中
gms-rt-usbip-connect 📋 复制
💡 可连接本地 Windows 电脑的ADB设备用于测试
📶 步骤4: WiFi连接配置 (可选)
gms-rt-devices-wifi RK3572GMS4 SSID password 📋 复制
💡 如果设备需要WiFi连接执行测试时使用
📚 步骤5: 查看测试套件
gms-rt-test-suites 📋 复制
💡 列出所有配置的测试套件
gms-rt-test-suites-result ~/GMS-Suite/android-vts/tools 📋 复制
💡 查看指定套件的测试结果历史
▶️ 步骤6: 启动测试
gms-rt-test-start RK3572GMS4 CTS ~/GMS-Suite/android-cts/tools 📋 复制
💡 启动CTS测试，会自动锁定设备
gms-rt-test-start RK3572GMS4 CTS CtsKeystoreTestCases android.keystore.cts.KeyAttestationTest#testRsaAttestation 📋 复制
💡 运行指定模块和用例
📊 步骤7: 实时查看测试日志
gms-rt-test-logs-stream 📋 复制
💡 实时流式显示测试日志输出（使用Ctrl+C退出）
📈 步骤 8: 查看测试结果
gms-rt-reports-list 📋 复制
💡 列出所有测试报告，查看最新测试结果
🧹 步骤 9: 清理测试环境 (可选)
gms-rt-test-clean 📋 复制
💡 清理测试日志和临时文件，释放磁盘空间

🔄 retry测试流程指南

步骤1: 查看测试结果
gms-rt-test-suites-result ~/GMS-Suite/android-vts/tools 📋 复制
步骤2: 启动VTS重试
gms-rt-test-start --retry 2026.04.17_14.32.32 RK3572GMS4 VTS 📋 复制
步骤3: 查看日志
gms-rt-test-logs-stream 📋 复制

💡 常用命令快速参考

• gms-rt-devices-info - 获取详细设备信息
• gms-rt-devices-user-locked - 检查设备锁状态
• gms-rt-reports-list - 列出所有测试报告
