5 步快速开始测试

  1. 登录并选工作区单机工作区选择本地 Worker；集群工作区选择远端 Worker。该选择仅属于当前用户，不会切换整个服务。
  2. 选择执行环境在“测试界面”先选 Worker、测试套件和可用设备。
  3. 设置测试范围按需选择测试模块、测试用例或retry报告等任务；留空则执行套件默认范围。
  4. 开始测试确认参数后点击“开始测试”，页面自动切到“测试日志”。
  5. 处理本次报告完成后在“报告管理”按 Worker、用户和时间戳确认已登记报告，可分析、Retry 或下载；Worker 原生 results/logs 从“测试套件”浏览器查看。

常用操作流程

🤖 手动测试

Worker → 测试类型 → 套件 → 可用设备 → 测试模块/测试用例 → 开始测试
设备显示“占用/锁定”时不可选择；模块和用例需匹配当前套件。Retry 先确认同一 Worker 的原始报告。

📱 设备与烧写

选设备 → 设备信息 / 系统操作 / 烧写固件 / 烧写 GSI
设备操作开始后自动切到“系统日志”。烧写前必须复核设备和镜像路径，过程中不要断电或拔线。

⚙️ GMS ATS 自动化

发起 → Profile → 固件/构建参数 → Worker / 设备 / 套件 → 预检 → 创建运行
选择已有固件或配置编译服务器、模板、源码目录与 Lunch Target；烧写模式限选 1 台本地 USB / USB-IP 设备。在“追踪与诊断”查看阶段进度，“测试报告”查看结果，“平台”检查资源。

🖥️ 远程主机与集群

主机集群 → 确认 Worker 在线 → 返回业务页选择 Worker
主机桌面、主机终端、设备与套件会跟随当前工作区 Worker；刷新期间保留已显示内容，只在新数据齐备后更新。

🔌 ADB / USB/IP 接入

选择来源 → 选择目标 Worker → 选择设备/BUSID → 核对当前接入
ADB Proxy 适合 ADB/测试，不支持 Fastboot/烧写；USB/IP 提供物理 USB 通道。测试占用期间禁止断开，重复操作会被服务端拒绝。

💬 对话 Agent

描述目标 → kkagent 查询资源 / 补齐参数 → 预检计划 → 按提示确认 → 跟踪步骤
对话引擎与报告分析模型的状态分别显示。需确认的操作会展示计划，预检未通过时先处理阻塞项再重新规划；规划失败可重试，历史会话可继续或导出。

📦 上传与恢复

选择文件 → 分块暂存 → 校验 → 执行/分析
固件先完成可恢复的分块暂存，再进入不可中断烧写；APK 最近任务可恢复，报告页始终以最后一次选择为准。

📚 SDK 源码配置

用户管理 → SDK 配置 → 添加 SDK → 发现目录 → 勾选 / 校验 → 添加
支持本机 Git 与编译服务器只读源码；可批量选择 Android 源码根目录，自动识别 Android 版本并允许修正。列表按版本统计，取证时还需匹配 revision / commit。

🔑 外部 Agent 接入

用户管理 → Agent 接入 → 创建配对码 → 安装配对 → 自检
管理员配置 scope、Worker 和设备范围；配对码 5 分钟有效、单次使用，凭据有效期另行设置。安装后用 gms-agent doctor --json 验收；存在多个 Profile 时明确选择目标。

🔎 工单分析与证据

选择 Redmine 工单 → 检查取证权限 → 分析进度 → 查看总结与引用
工单分析会读取日志及匹配版本的 APK / SDK 证据，并在发布前复核结论。对话直接展示总结；证据不足时保留待验证项，高影响归因仍需工程复现。

功能入口速查

测试界面配置并执行 CTS / GTS / VTS / STS；查看系统日志与测试日志。设备管理查看设备状态、占用关系和远端设备操作入口。
设备串口查看 Controller 本机 USB 串口、实时控制台和开机早期日志。主机桌面 / 终端通过 noVNC 或终端操作当前 Worker 主机。
测试套件管理各 Worker 套件，浏览原生 results/logs 和测试结果。报告管理 / 分析检索已登记报告，分析失败项、Retry、下载或分享结果。
GMS ATS编排构建、设备预留、烧写、测试与报告全流程。主机集群查看 Worker 在线状态、能力和任务分配；刷新时保留稳定内容。
ADB / USB/IP在“本地设备/ADB接入”中管理来源、目标、设备与逐端口接入。APK / Agent恢复 APK 历史任务；以受控计划执行 Agent 支持的查询和操作。
用户管理用户列表、Agent 接入凭据与 SDK 源码配置。Redmine / Gerrit工单取证、分析结论与代码评审；相关入口按权限展示。
系统架构平台分层与拓扑、USB/IP、AOA 恢复和固件烧写链路。其他工具GMS 助手、知识检索、便签、常用网站与实用工具。
安全与日志：“开始测试”进入测试日志；烧写固件、烧写 GSI、设备信息和其他设备操作进入系统日志。固件上传暂存阶段可重试，进入最终烧写后不可强制停止；异常时保留日志和任务编号。ADB Proxy/USB/IP 断开会核对设备占用，不能用来绕过租约。

① 测试实例

标注测试类型自动匹配套件，以及测试模块、测试用例、Retry 报告和执行 Worker 的填写规则。

② 设备投屏

选择设备后启动 scrcpy，并说明投屏画面入口和 VNC/scrcpy 日志排查位置。

③ 本地设备 USB/IP

明确来源、目标 Worker 和 BUSID；逐端口查看/断开，并说明测试占用与重复操作保护。

④ 报告管理

说明测试结束后的完整处理链路；删除不可恢复，results 与 logs 分别打开对应时间戳目录。

⑤ 报告分析

从总体通过率定位到具体失败模块和用例，并继续单测复现、诊断或分享分析结果。

⑥ APK 分析

覆盖最近任务恢复、文件上传、反编译源码下载、Manifest/权限/源码视图切换和文件检索。

⑦ 测试套件

明确 Worker、套件、测试任务必须一致，并说明结果列表以及 results/logs 目录关系。

⑧ GMS ATS

重点标出源码目录与 Lunch Target 的绑定关系，以及运行创建后的监控入口。

⑨ 设备烧写

高风险操作单独说明设备核对、固件/GSI 入口、设备信息和系统日志；固件先分块暂存校验，最终烧写阶段才锁定界面。

⑩ 对话 Agent

区分对话引擎和分析模型，展示资源预检、计划确认、步骤追踪与历史会话。

⑪ 主机集群刷新

展示刷新期间保留稳定页面、阻止重复刷新以及局部接口失败不影响其他区域。
