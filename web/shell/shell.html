管理员账号，或 用户名@客户端IP（SSH 账号）。
管理员用平台密码；客户端用 SSH 密码。
请输入安装时生成的初始化令牌。
如何获取初始化令牌
在 Controller 安装目录下，以服务运行用户或管理员身份执行：
python3 -c 'import json; print(json.load(open("configs/secrets/environment.json"))["GMS_BOOTSTRAP_TOKEN"])'
将输出填入上方。默认目录：/opt/gms-remote-test/web_app。
手动部署：使用 Controller configs/local/environment.json 中的 GMS_BOOTSTRAP_TOKEN。
