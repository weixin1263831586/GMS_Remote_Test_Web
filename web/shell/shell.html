GMS Remote Test 快速操作指南

先确定测试主机和设备，再执行测试或固件烧写；运行过程分别在测试日志和系统日志中查看。

当前访问地址 ↗

5 步快速开始测试

  1. 登录并选工作区单机工作区选择本地 Worker；集群工作区选择远端 Worker。该选择仅属于当前用户，不会切换整个服务。
  2. 选择执行环境在“测试界面”先选 Worker、测试套件和可用设备。
  3. 设置测试范围按需选择测试模块、测试用例或retry报告等任务；留空则执行套件默认范围。
  4. 开始测试确认参数后点击“开始测试”，页面自动切到“测试日志”。
  5. 处理本次报告完成后进入“报告管理”，按 Worker、用户和时间戳确认报告，可分析、Retry、下载或查看 results/logs。

常用操作流程

🤖 手动测试

测试类型 → 套件 → Worker → 可用设备 → 测试模块/测试用例 → 开始测试
设备显示“占用/锁定”时不可选择；结束后在报告页按 Worker、设备或套件筛选。

📱 设备与烧写

选设备 → 设备信息 / 系统操作 / 烧写固件 / 烧写 GSI
设备操作开始后自动切到“系统日志”。烧写前必须复核设备和镜像路径，过程中不要断电或拔线。

⚙️ GMS ATS 自动化

Profile → 构建参数 → Worker → 设备 → 套件 → 创建运行
启用构建时依次选择编译服务器、模板、源码目录；Lunch Target 只显示当前源码目录扫描结果。运行详情可追踪构建、烧写、测试和报告。

🖥️ 远程主机与集群

主机集群 → 确认 Worker 在线 → 返回业务页选择 Worker
主机桌面、主机终端、设备与套件会跟随当前工作区 Worker；刷新期间保留已显示内容，只在新数据齐备后更新。

🔌 ADB / USB/IP 接入

选择来源 → 选择目标 Worker → 选择设备/BUSID → 核对当前接入
ADB Proxy 适合 ADB/测试，不支持 Fastboot/烧写；USB/IP 提供物理 USB 通道。测试占用期间禁止断开，重复操作会被服务端拒绝。

💬 对话 Agent

输入意图 → 查看计划 → 人工确认 → 跟踪步骤
Agent 是确定性工具编排器，不会无人值守接管项目或任意执行代码。本地/备用模型仅用于报告和知识分析，状态在步骤区单独显示。

📦 上传与恢复

选择文件 → 分块暂存 → 校验 → 执行/分析
固件先完成可恢复的分块暂存，再进入不可中断烧写；APK 最近任务可恢复，报告页始终以最后一次选择为准。

功能入口速查

测试界面配置并执行 CTS / GTS / VTS / STS；查看系统日志与测试日志。设备管理查看设备状态、占用关系和远端设备操作入口。
主机桌面 / 终端通过 noVNC 或终端操作当前 Worker 主机。测试套件下载、添加、解压并检查不同 Worker 上的套件。
报告管理 / 分析检索、下载测试报告，并汇总失败项和趋势。GMS ATS编排构建、设备预留、烧写、测试与报告全流程。
主机集群查看 Worker 在线状态、能力和任务分配；刷新时保留稳定内容。ADB / USB/IP在“本地设备/ADB接入”中管理来源、目标、设备与逐端口接入。
APK / Agent恢复 APK 历史任务；以受控计划执行 Agent 支持的查询和操作。其他工具GMS 助手、Gerrit、Redmine和知识库用于分析与协作。
安全与日志：“开始测试”进入测试日志；烧写固件、烧写 GSI、设备信息和其他设备操作进入系统日志。固件上传暂存阶段可重试，进入最终烧写后不可强制停止；异常时保留日志和任务编号。ADB Proxy/USB/IP 断开会核对设备占用，不能用来绕过租约。

① 测试实例

标注测试类型自动匹配套件，以及测试模块、测试用例、Retry 报告和执行 Worker 的填写规则。

② 设备投屏

选择设备后启动 scrcpy，并说明投屏画面入口和 VNC/scrcpy 日志排查位置。

③ 本地设备 USB/IP

明确来源、目标 Worker 和 BUSID；逐端口查看/断开，并说明测试占用与重复操作保护。

④ 报告管理

说明测试结束后的完整处理链路；删除不可恢复，results 与 logs 分别打开对应时间戳目录。

⑤ 报告分析

从总体通过率定位到具体失败模块和用例，并继续单测复现、诊断或分享分析结果。

⑥ APK 分析

覆盖最近任务恢复、文件上传、反编译源码下载、Manifest/权限/源码视图切换和文件检索。

⑦ 测试套件

明确 Worker、套件、测试任务必须一致，并说明结果列表以及 results/logs 目录关系。

⑧ GMS ATS

重点标出源码目录与 Lunch Target 的绑定关系，以及运行创建后的监控入口。

⑨ 设备烧写

高风险操作单独说明设备核对、固件/GSI 入口、设备信息和系统日志；固件先分块暂存校验，最终烧写阶段才锁定界面。

⑩ 对话 Agent

说明自然语言计划、人工确认、模型可用性和设备租约/Worker 能力检查之间的边界。

⑪ 主机集群刷新

展示刷新期间保留稳定页面、阻止重复刷新以及局部接口失败不影响其他区域。

                📖 GMS测试流程指南
                ×
            

            

                

                    
🚀 完整测试流程指南


                    
                    

                        
📦 步骤1: 一键安装Skill和CLI（可在任意Linux主机执行）

                        

                            curl {% if request.url.scheme == 'https' %}-k {% endif %}-fsSL "{{ request.url.scheme }}://{{ request.url.netloc }}/api/system/skills/install.sh" | bash
                            📋 复制
                        

                    


                    

                        

                            gms-rt-auth-login USERNAME && gms-rt-devices-list
                            📋 复制
                        

                        
💡 无需解压或source；重复执行安装命令即可更新，也可运行 gms-rt-update

                    


                    
                    

                        
🏥 步骤2: 测试主机网络连通性检查

                        

                            gms-rt-ssh-ping
                            📋 复制
                        

                    


                    

                        

                            gms-rt-vpn-status
                            📋 复制
                        

                        
💡 检查VPN连接状态（如果需要VPN访问设备）

                    


                    
                    

                        
📱 步骤3: 设备检查

                        

                            gms-rt-devices-list
                            📋 复制
                        

                        
💡 列出所有可用的测试设备，确认目标设备在列表中

                    


                    

                        

                            gms-rt-usbip-connect
                            📋 复制
                        

                        
💡 可连接本地 Windows 电脑的ADB设备用于测试

                    


                    
                    

                        
📶 步骤4: WiFi连接配置 (可选)

                        

                            gms-rt-devices-wifi RK3572GMS4 SSID password
                            📋 复制
                        

                        
💡 如果设备需要WiFi连接执行测试时使用

                    


                    
                    

                        
📚 步骤5: 查看测试套件

                        

                            gms-rt-test-suites
                            📋 复制
                        

                        
💡 列出所有配置的测试套件

                    


                    

                        

                            gms-rt-test-suites-result ~/GMS-Suite/android-vts/tools
                            📋 复制
                        

                        
💡 查看指定套件的测试结果历史

                    


                    
                    

                        
▶️  步骤6: 启动测试

                        

                            gms-rt-test-start RK3572GMS4 CTS ~/GMS-Suite/android-cts/tools
                            📋 复制
                        

                        
💡 启动CTS测试，会自动锁定设备

                    


                    

                        

                            gms-rt-test-start RK3572GMS4 CTS CtsKeystoreTestCases android.keystore.cts.KeyAttestationTest#testRsaAttestation
                            📋 复制
                        

                        
💡 运行指定模块和用例

                    


                    
                    

                        
📊 步骤7: 实时查看测试日志

                        

                            gms-rt-test-logs-stream
                            📋 复制
                        

                        
💡 实时流式显示测试日志输出（使用Ctrl+C退出）

                    



                    
                    

                        
📈 步骤 8: 查看测试结果

                        

                            gms-rt-reports-list
                            📋 复制
                        

                        
💡 列出所有测试报告，查看最新测试结果

                    


                    
                    

                        
🧹 步骤 9: 清理测试环境 (可选)

                        

                            gms-rt-test-clean
                            📋 复制
                        

                        
💡 清理测试日志和临时文件，释放磁盘空间

                    


                    
🔄 retry测试流程指南


                    
                    

                        
步骤1: 查看测试结果

                        

                            gms-rt-test-suites-result ~/GMS-Suite/android-vts/tools
                            📋 复制
                        

                    


                    

                        
步骤2: 启动VTS重试

                        

                            gms-rt-test-start --retry 2026.04.17_14.32.32 RK3572GMS4 VTS
                            📋 复制
                        

                    


                    

                        
步骤3: 查看日志

                        

                            gms-rt-test-logs-stream
                            📋 复制
                        

                    


                    
💡 常用命令快速参考

                    

                        

                            
• gms-rt-devices-info - 获取详细设备信息

                            
• gms-rt-devices-user-locked - 检查设备锁状态

                            
• gms-rt-reports-list - 列出所有测试报告
