可使用平台管理员账号，或 SSH用户名@客户端IP，例如 gms@192.0.2.10。
管理员请输入平台密码；客户端账号请输入 SSH 密码（通常与系统登录/锁屏密码相同）。
一键安装会自动生成令牌，保存在 Controller 安装目录的 configs/secrets/environment.json 中，字段名为 GMS_BOOTSTRAP_TOKEN；仅用于创建首个管理员。
如何获取初始化令牌 在 Controller 服务器上，以服务运行用户或管理员身份进入实际安装目录，执行： python3 -c 'import json; print(json.load(open("configs/secrets/environment.json"))["GMS_BOOTSTRAP_TOKEN"])' 将输出粘贴到上方。默认安装目录为 /opt/gms-remote-test/web_app。手动部署请使用为 Controller 配置的同名环境变量；配置统一保存在 configs/local/environment.json。
